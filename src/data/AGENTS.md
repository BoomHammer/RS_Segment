# 数据模块说明 Data Module Instructions
### 职责Responsibility
data/ 负责：  
数据集访问  
数据解析  
预处理  
数据增强  
采样  
批处理 (batching)  
与数据相关的转换  
它不得包含模型架构或训练目标的逻辑。

### 数据特点
要注意遥感影像的值范围不同，且差距巨大。空间分辨率不同、坐标系不同。
#### 静态遥感数据
文件位置：data\raw\static
单个文件即为一个系列，无时间信息
#### 动态遥感数据
文件位置：data\raw\dynamic  
文件名包括系列名和6位数字时间，例如“EVI230117.tif”代表2023年01月17日EVI数据，“FPAR231024.tif”代表2023年10月24日FPAR数据。  
上述为时间分辨率为8天/16天数据的格式，还有时间分辨率为月的数据，系列名后跟4位数字时间，例如“PR2303.tif”代表2023年03月PR数据。  
最特殊的是SR数据，为多波段影像，拆分成多波段存储。命名格式为SR时间波段，例如“SR230218B3.tif”代表2023年02月18日的第3波段SR数据。  
#### 标签数据
文件位置：data\labels
### 输出结果
所有处理好的数据存入data\processed，后续计算可直接读取，避免每次实验重复计算
