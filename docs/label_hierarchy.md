# 分类层级配置

`configs/data.yaml` 的 `data.label_schema.levels` 按从粗到细列出 1～4 层。
列表长度决定最大分类深度；训练标签、弱标签和预测 GeoTIFF 使用统一的叶类 ID。
每层的 `name` 用于图例和评估，`column` 是 CSV 类别列，`zh_column` 是可选中文展示列。
类别名称可以直接使用中文，无需额外生成英文列。

```yaml
label_schema:
  version: 3
  encoding: utf-8-sig
  first_id: 1
  missing_policy: partial
  optional_leaf_level: true
  min_samples_per_fine_class: 10
  columns:
    index: 编号
    x: X
    y: Y
  levels:
    - {name: 一级类, column: First_Cata, zh_column: 一级类}
    - {name: 二级类, column: Second_Cata, zh_column: 二级类}
    - {name: 三级类, column: Third_Cata, zh_column: 三级类}
    - {name: 四级类, column: Fourth_Cata, zh_column: 四级类}
```

当前文件为 `data/labels/YRBmerge20261016.csv`，启用 `optional_leaf_level`：

- 没有观测到四级细分的三级类直接作为叶类输出，中文图例的四级列留空。
- 有四级细分的三级类按已填四级分类，并自动建立 `Other_三级英文名` / `其它三级中文名`。
  该分支四级空白的样本归入这个“其它”类；即使没有空白样本，也会建立兜底类。
- 当前有细分的分支是水浇地、旱地、灌木园地，分别生成其它水浇地、其它旱地、其它灌木园地。
- 只有一级或前两级的样本仍按部分标签监督，不推测三级类。

内部用单子节点把粗层叶类延续到第四个张量层，使现有 SAM 弱标签、窗口读取和融合流程
继续使用统一叶类 ID。这不代表新增语义类别：映射的 `terminal_level` 标记实际终止层级，
导出的图例不展示内部占位名称，更深层损失及逐层评估均排除这些粗层叶类。
`default_leaf_paths` 保存空四级的确定性编码规则，checkpoint 的 `leaf_depths` 绑定实际分类深度。
这些规则依据完整父子路径生效，不会把不同分支的同名类别合并。

`min_samples_per_fine_class: 10` 按每个类别的**独立坐标数**判断低频：

- 同类同坐标重复记录计一次；同坐标不同类别分别保留。不同坐标即使落入同一目标像元，也分别计数。
- 一级类始终保留。二级类不足 10 个坐标时，其下样点并入一级；三级类不足 10 个时并入二级。
  上级计数包含全部后代和仅标到该层的样点，以坐标集合去重，避免同一坐标在多个子类中重复累计。
- 四级类不足 10 个时归入所属三级类的“其它”；恰好 10 个保留。自动生成的“其它”类不再次按阈值删除。
- 合并后的上级若还有保留的子类，这些样点只监督该上级，未知下层为 `-1`；不会被猜成某个兄弟类别。
  上级若已无保留子类，则成为实际的粗层叶类。只有一级/二级的原始样点始终合法。

`coarsened_classes` 记录被合并路径、独立坐标数和目标路径；`path_aliases` 固定原始标签的编码规则，
并与模型 checkpoint 绑定。阈值合并不受参考栅格分辨率和 CSV 行顺序影响。
关闭 `optional_leaf_level` 后，只保留一个条目即可做单层分类；保留两个条目即为两层分类。
例如只保留 `三级类` 时，三级类作为平面类别直接分类，同名类别会合并；
使用完整三层时，类别 ID 根据完整路径生成，不同父类下的同名子类分别编码。
坐标 CRS 由独立的 `data.label_crs` 指定，当前 CGCS2000 经纬度使用 `EPSG:4490`。

当前配置采用 `missing_policy: partial`。经过可选四级规则处理后，只有一级类时只监督一级，有一级和二级时
只监督前两级。未知子类保持未标注，不填充为某个子类，也不作为新的“未知”类别。
即使某节点只有一个子类，也不会将缺失的观测自动补成该子类标签。
数据增强、按点采样、重叠训练和空间归属掩码均保留这些部分标签。
SAM 叶类弱标签仅使用完整路径样点，部分标签留作对应层级的实测监督。
逐层评估使用该层有标注的独立像元，部分标签不参与未知下层的准确率计算。

只允许连续的已知前缀；例如“一级有值、二级空白、三级有值”会报错。
普通固定深度模式的类别体系由完整路径建立，部分标签所属父类必须在完整路径中出现。
可选四级模式允许整条分支终止在已知上级，直接作为粗层叶类，不推测子类。
校验报告的 `partial_rows`、`partial_label_rows`、`partial_depth_counts` 分别记录原始合法部分标签的
数量、CSV 行号（包含表头）和已知层级深度；这不是错误。`coarsened_rows` 单列因低频合并而改变的记录数。
`missing_hierarchy_rows` 现在只记录无效层级缺失（如跨级空白，或 error/skip 模式不允许的缺失），
合法的仅一级/二级标签不再放入此字段。坐标错误仍算无效行。
仍可选择 `error`（缺失即报错）或 `skip`（跳过并记录缺失层级行号）。

同坐标/同目标像元的类别分歧不再由最后一行覆盖。加载时保留每个 `(坐标, 类别路径)` 观测，
完全重复的观测去重；某一层一致时仍用硬标签，该层有分歧时按已知观测频次形成软监督。
每个像元每层的总实测权重为 1，避免密集重复采样使某个像元支配训练；未知层不参与该层统计。
例如一个像元有两个独立坐标支持 A、一个支持 B，该层损失为 `2/3 × loss(A) + 1/3 × loss(B)`。
这表示样点证据分布，**不是推定地物面积占比**。
稀疏观测表随翻转、旋转、核心窗口和空间划分掩码同步处理，不创建整幅稠密多类软标签栅格。
类别覆盖审计保留混合像元中的每个类别，同一像元仍只有一个 train/validation/test 归属。
实测混合像元位置屏蔽单类 SAM 伪标签，不删除原始实测点。

SAM 扩展区域先对每个类别取候选分数的最大值，再比较不同类别：只有最高分比次高分
高出 `weak_label.conflict_margin`（当前为 0.05），才输出最高分类别；否则输出 NoData。
候选分数仍为像元分数乘以掩膜置信度。同类重复候选不增加票数，也不参与异类冲突判断。
冲突后保留两个不同类别的最高分，后来的同分或低分候选不会把冲突像元重新填上；
后续候选若形成明确领先，则可以输出该类别。结果不受样点顺序或多卡分片方式影响。
实现使用磁盘映射保存每像元的两个候选，不创建全图逐类别概率张量，不增加 GPU 显存占用。
分片合并和恢复核验都读取两候选记录；旧版弱标签断点/分片已丢失冲突证据，不能直接续用，需重新生成。

评估把确定标签的准确率与 `mixed_pixels` 中的观测分布一致度、交叉熵分别报告；
共有上级仍参与该上级的普通准确率。混合像元在重叠窗口间去重，不强行指定一个“唯一真类”。
仅在所选验证层完全没有确定标签时，使用明确标记 `selection_target_type: mixed_observation_distribution`
的分数进行模型选择。校验报告的 `mixed_coordinate_count` 是有分歧的独立坐标数，
`conflicting_duplicate_points` 是遇到分歧的重复记录次数，两者含义不同；例子见 `mixed_coordinate_examples`。
预测 GeoTIFF 仍输出单一类别，混合观测用于训练与单独评估；实测覆盖选项不会强制改写混合像元。

映射 JSON 保存每层类别数、相邻层父类关系，以及每个叶子类别的完整路径和各层 ID。
数字 ID 从 1 开始；模型内部的父类索引从 0 开始。
历史 `formation`/`alliance` 字段作为根层/叶层的兼容别名保留。
未配置 `levels` 的旧配置和旧两层模型仍可使用。

四层概率为 `P(一级) × P(二级 | 一级) × P(三级 | 二级) × P(四级 | 三级)`，逐层归一化；
训练时由真实叶子标签查找各层祖先进行监督，保留实测/弱标签权重、类别权重和有效像元掩码。
单层只有一个分类头和一项分类监督。现有 SegFormer（MiT-B1 编码器）+U-TAE、分支消融、MAESTRO、AnySat
共享这一契约。这里的 SegFormer+U-TAE 对应命令行 `--model segformer-utae`，
内部架构名为 `segformer_utae_pretrained`，通过统一的 `HierarchicalHeads.from_derived` 创建层级分类头。
层级增加只增加分类头，不复制编码器；条件概率累积使用 FP32，兼容 BF16。
父类只有一个子类时，该条件 softmax 恒为 1，子类概率等于父类概率，不要求每个节点至少两个子类。

当前 `model.supervision.level_weights: [1.0, 0.5, 0.25, 0.1]` 按一级到四级递减。
它们分别乘每层的实测/弱标签监督损失，实测与弱标签原有的来源权重继续生效。
下层联合概率仍包含上级概率，因此下层训练也会反馈到上级；这些数值是优化偏好，不是准确率保证。
未配置时保留各层等权的兼容行为；显式配置的长度必须与分类层数一致。
切换回一至三级实验时，需要同步调整此权重列表并关闭可选四级模式。

`training.selection_level: 0` 指定训练验证以一级类为准，当前最佳模型和早停监控
一级类的 `val_macro_f1`，避免只追求少数大样本类的总体准确率。
验证 JSON 同时保留 `levels` 中每层的 accuracy、macro F1、召回率和独立样点数，
`leaf` 单独保存混合叶类指标。三级约 70% 是需要用独立空间测试集检验的目标；
应同时查看总体准确率和 macro F1，不能把样点很少或无测试样点的类视为已达到目标。

推理继续使用叶子类别概率进行 halo 和重叠融合。图例包含全部配置层级，
测试报告的 `levels` 字段分别输出每层指标。模型权重与完整分类路径绑定，
预测和测试会拒绝不匹配的映射，避免类别数字与图例错配。
若验证集只有部分标签而无叶类标签，训练验证指标明确记录 `selection_level`，
未配置优先层级时使用有标注的最深层；显式配置时该层必须有验证样点。
独立测试报告的叶类指标在无叶类样点时为 `null`。

`data.stage2.split.min_class_points_per_split` 默认是 2。对于训练、验证、测试三者均启用，
总样点不足 6 个，或独立空间块不足 3 个的类别，其所在空间块全部保留在训练集。
其余类别按空间块进行分层优化，并修复训练集缺类情况；不复制样点到不同划分。
因此比例是软目标，稀有类别与常见类别共块时，常见类别的实际比例也会变化。
`spatial_split.json` 的 `class_coverage` 记录样点数、空间块数、实际划分计数和评估不足的划分。
评估报告记录 `classes_without_ground_truth`，不能对缺少独立样点的类别声称泛化精度。
若保留稀有类别后验证集完全为空，训练会提示验证集为空，需要增加独立样点或调整空间块配置。

切换层级或改动类别后，必须重新生成标签映射、弱标签和数据集，并重新训练。
不要将旧弱标签栅格或旧训练断点直接配上新的分类映射。
