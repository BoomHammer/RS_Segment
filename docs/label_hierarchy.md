# 分类层级配置

`configs/data.yaml` 的 `data.label_schema.levels` 按从粗到细列出 1、2 或 3 层。
列表长度决定分类深度，最后一层始终是训练标签、弱标签和预测 GeoTIFF 的类别。
每层的 `name` 用于图例和评估，`column` 是 CSV 类别列，`zh_column` 是可选中文展示列。
类别名称可以直接使用中文，无需额外生成英文列。

```yaml
label_schema:
  version: 2
  encoding: gb18030  # UTF-8 CSV 使用 utf-8-sig
  first_id: 1
  missing_policy: partial
  columns:
    index: 编号
    x: 经度CGCS2000
    y: 纬度CGCS2000
  levels:
    - {name: 一级类, column: 一级类}
    - {name: 二级类, column: 二级类}
    - {name: 三级类, column: 三级类}
```

只保留一个条目即可做单层分类；保留两个条目即为两层分类。
例如只保留 `三级类` 时，三级类作为平面类别直接分类，同名类别会合并；
使用完整三层时，类别 ID 根据完整路径生成，不同父类下的同名子类分别编码。
坐标 CRS 由独立的 `data.label_crs` 指定，当前 CGCS2000 经纬度使用 `EPSG:4490`。

当前配置采用 `missing_policy: partial`。只有一级类时只监督一级，有一级和二级时
只监督前两级。未知子类保持未标注，不填充为某个子类，也不作为新的“未知”类别。
即使某节点只有一个子类，也不会将缺失的观测自动补成该子类标签。
数据增强、按点采样、重叠训练和空间归属掩码均保留这些部分标签。
SAM 叶类弱标签仅使用完整路径样点，部分标签留作对应层级的实测监督。
逐层评估使用该层有标注的独立像元，部分标签不参与未知下层的准确率计算。

只允许连续的已知前缀；例如“一级有值、二级空白、三级有值”会报错。
类别体系由完整路径建立，所以部分标签所属父类必须在至少一条完整路径中出现。
若整个父类从未提供过任何完整路径，程序会明确报错：需要先补充类别体系，不能凭空推测子类。
校验报告单列 `partial_rows`；合法部分标签算有效行，坐标错误仍算无效行。
仍可选择 `error`（缺失即报错）或 `skip`（跳过并记录缺失层级行号）。

映射 JSON 保存每层类别数、相邻层父类关系，以及每个叶子类别的完整路径和各层 ID。
数字 ID 从 1 开始；模型内部的父类索引从 0 开始。
历史 `formation`/`alliance` 字段作为根层/叶层的兼容别名保留。
未配置 `levels` 的旧配置和旧两层模型仍可使用。

三层概率为 `P(一级) × P(二级 | 一级) × P(三级 | 二级)`，逐层归一化；
训练时由真实叶子标签查找各层祖先进行监督，保留实测/弱标签权重、类别权重和有效像元掩码。
单层只有一个分类头和一项分类监督。现有 MiT+U-TAE、分支消融、MAESTRO、AnySat
共享这一契约。层级增加只增加分类头，不复制编码器；条件概率累积使用 FP32，兼容 BF16。
父类只有一个子类时，该条件 softmax 恒为 1，子类概率等于父类概率，不要求每个节点至少两个子类。

推理继续使用叶子类别概率进行 halo 和重叠融合。图例包含全部配置层级，
测试报告的 `levels` 字段分别输出每层指标。模型权重与完整分类路径绑定，
预测和测试会拒绝不匹配的映射，避免类别数字与图例错配。
若验证集只有部分标签而无叶类标签，训练验证指标明确记录 `selection_level`，
使用有标注的最深层；独立测试报告的叶类指标则为 `null`。

`data.stage2.split.min_class_points_per_split` 默认是 2。对于训练、验证、测试三者均启用，
总样点不足 6 个，或独立空间块不足 3 个的类别，其所在空间块全部保留在训练集。
其余类别按空间块进行分层优化，并修复训练集缺类情况；不复制样点到不同划分。
因此比例是软目标，稀有类别与常见类别共块时，常见类别的实际比例也会变化。
`spatial_split.json` 的 `class_coverage` 记录样点数、空间块数、实际划分计数和评估不足的划分。
评估报告记录 `classes_without_ground_truth`，不能对缺少独立样点的类别声称泛化精度。
若保留稀有类别后验证集完全为空，训练会提示验证集为空，需要增加独立样点或调整空间块配置。

切换层级或改动类别后，必须重新生成标签映射、弱标签和数据集，并重新训练。
不要将旧弱标签栅格或旧训练断点直接配上新的分类映射。
